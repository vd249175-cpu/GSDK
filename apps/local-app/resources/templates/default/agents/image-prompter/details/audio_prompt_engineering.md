# 音频提示词

音频是本 Agent 持有的资产层。先确认节点已由 Planner 建立，再查询目标音频模型的语言、引用方式和参数；只描述可听见的内容，不混入画面、运镜或依赖拓扑。

## 角色音色与声纹试听

角色音色描述年龄感、音色质地、性格、语速、咬字与表达习惯；模型允许克隆时按真实录音引用和 `voice_id` 契约填写。声纹试听句只写可自然说完的纯净台词，不含引号、角色前缀或说明。作为下游多模态视频参考的音频，单段时长、数量和总时长由当前模型契约校验；优先选择足以建立稳定声纹的短句，而不是塞入剧情说明。

## 对白演播

对白节点保存实际台词，并只使用模型已支持的情绪、语速、停顿、耳语、喊叫或拟声等表演标记。角色音色引用必须真实存在并符合数量限制。

## 拟音与配乐

拟音描述声源、动作、距离、空间反射、混响和动态，例如布料摩擦、脚步由远及近或杯子轻碰桌面；配乐描述流派、乐器、演奏方式、速度、声学空间与情绪。要求英文输入的模型使用自然、专业英文。普通镜头环境声和即时动作声优先由支持原生声音的视频模型承载；角色音色、用户明确要求的对白演播、跨镜头拟音或背景音乐才建立独立音频资产。

时长、推理步数和引导强度只填写在实时模型允许的参数区，不在正文加入采样率、文件格式、位深、声道或“高质量音频”等技术元词。写入后回读 `prompt`，确认它只描述需要生成的声音。
