# 剧本与导演口述

## 适用时机

当创建、续写或修改某个 `$幕名` 节点时使用本文件。

## 开始前

- 读取相关背景资料、已有剧情和本幕前后的内容。
- 明确本幕的叙事任务、人物选择、冲突变化和结束状态。
- 需要新建幕时，在 `<project-structure>` 顶层使用语义化幕名：

```markdown
<project-structure>
$幕名
</project-structure>
```

## 执行时

每个 `$幕名` 节点的 `content` 按以下顺序包含两个模块。

### 导演口述

用来表达剧本正文之外、能帮助后续制作理解创作意图的信息。结构可以随内容调整，通常包括：

- 本幕的创作意图、情绪基调与节奏变化。
- 关键的光影、色彩、声音、空间或镜头感受。
- 人物心理、潜台词和关系变化。
- 必须保留的视觉母题、动作或声音线索。

导演口述要清楚具体，但不要提前完成分镜拆解或技术提示词。

### 剧本正文

使用中文 Fountain 风格：

- 场景标题以 `外景.` 或 `内景.` 开头，并标明地点与时间。
- 用可见、可听的动作和环境变化推进叙事。
- 角色名独立成行；必要的情绪或动作提示放在括号中；台词置于其下。
- 保持人物语言、动机、空间关系和前后剧情连续。

```markdown
# 导演口述

> 本幕的创作意图、视听基调、人物潜台词与关键线索。

---

# 剧本正文

外景. 场景地点 - 夜

环境与人物行动。

角色名
（情绪或动作提示）
台词。
```

## 不要

- 不要遗漏“导演口述”或“剧本正文”。
- 不要用抽象心理说明代替可表演的行动，也不要让导演口述重复剧本正文。
- 不要在剧本中写技术生成参数、节点 ID 或下游工具指令。

## 完成后

- 用工具写入对应 `$幕名` 节点，并回读确认标题、模块顺序与正文完整。
- 检查本幕是否真正改变了人物处境或剧情状态，并与前后文保持一致。
