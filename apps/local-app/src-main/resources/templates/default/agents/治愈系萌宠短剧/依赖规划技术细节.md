# 依赖规划技术细节

本文档专为依赖规划师 (Planner) Agent 规定在《治愈系萌宠短剧》项目中的工程依赖拓扑与节点规划规范。在生成工程结构、配置节点描述与挂载依赖时使用。

---

## 1. 分镜叙事解耦与同场景单幕合并生成
- **同场景不引入二次生成原则**：
  - 分镜正文保持清晰的叙事镜头段落划分，但在工程依赖拓扑层，**只要处于相同场景下且动作时长在模型生成窗口内，坚决合并为单个视频节点一次性生成，绝不引入多余的二次视频生成任务**；
  - 最大限度发挥长视频模型的全局时空连贯性与场景一致性，将全片任务量和流水线调度开销降至绝对最低。

---

## 2. 风格节点职责边界与双层风格体系（强约束）
- **风格不含镜头语言**：`&风格节点`（如 `&真实影视照片风格`、`&治愈系写实电影光影`）**绝对不包含任何镜头语言（景别、运镜、机位、推拉摇移、转场等）**。所有的景别变化、机位角度与运镜指令，专归下游提示词 Agent 在具体镜头中编写。
- **双层风格分离与解耦铁律（资产风格 vs 镜头风格）**：
  - **底层通用资产风格（`&真实影视照片风格`）**：
    - 专用于角色（`@角色`）、场景（`@场景`）、核心道具（`@核心道具`）的底图生成；
    - **全景深（Pan-focus）硬约束**：强制全画面清晰对焦、主体轮廓锐利、中性通透自然光照，**严禁加入浅景深虚化、背景光斑或特定暖调漫反射**，彻底避免资产底图将背景或光影“烘焙死”，确保资产在任何下游镜头中纯净可复用。
  - **上层视频镜头风格（`&治愈系写实电影光影`）**：
    - 专用于视频镜头（`%视频`）与关键帧（`@关键帧`）的生成；
    - 引入 4K 电影级高写实画质、柔和暖调自然散射光、微距浅景深虚化光斑与胶片级柔和影调，负责全片动态视听的情绪与光影渲染。

## 3. 角色声纹母带设计与时长硬约束（极简声纹规范）
- **正文即试听演播台词机制**：
  - `qwen-voice-design` 声纹节点的 **Markdown 正文（Prompt 正文）才是模型实际开口朗读并合成母带的语音台词**；
  - 声音人设与音色特征描述必须写入 YAML 头部的 `description` 参数中，**严禁将人设描述写在正文中（否则 TTS 引擎会将人设描述直接读出为语音）**；
  - `seed_text` 参数仅在传入真实参考录音进行特征克隆与文本对齐时使用，纯文本设计模式下留空，直接由正文提供试听台词。
- **极简身份句式（我是...）**：
  - 节点正文台词必须统一采用“**我是[角色名]...**”的极简句式（如“我是妈妈，啵啵要乖哦。”、“我是啵啵，喵！”、“我是朵朵。”），严禁在正文中写入长句或复杂剧情。
- **时长上限与视频模型契约**：
  - 声纹母带试听音频必须严格控制在 **2~3 秒** 的极短时长内；
  - **核心动因**：多模态视频生成模型对单段参考音频有 $\le 15\text{s}$ 的严格限制。极简短音频能够让模型在毫秒级内快速锁定音色特征，同时最大程度保留镜头视频的有效生成时长裕量，避免音频溢出或相位失真。
- **角色出声声纹硬绑定铁律**：
  - **凡是角色在镜头中出镜并说话，必须严格挂载对应的 `~角色声纹` 资产**，保证全剧音色一致性与声画口型对齐。

## 4. 资产贯穿与配乐纯净策略
- **贯穿资产锚点**：具有跨幕情感与故事闭环价值的道具（如 `@小黄鸭毛绒斜挎包`）作为全剧通用资产沉淀。
- **全片 BGM 坚持单乐器纯净音乐**：
  - 独立全片配乐必须采用**单一乐器独奏（如纯原木吉他指弹、纯尤克里里独奏）**；
  - **严禁复合乐器混音**，严禁叠加鼓点节奏组、合成器或副乐器，保持温润清澈的纯净治愈感；
  - 配乐节点独立于具体镜头，作为通用音频资产供剪辑后期铺底。
- **镜头内音频依赖极简**：普通环境声与即时动作拟音优先交由视频生成模型原生生成，不额外堆叠浅层独立音频节点。

---

## 5. 关键帧策略与去编号化命名
- **关键帧与起始帧非必要原则（灵活按需，支持零关键帧直出）**：
  - **镜头起始帧并非必要创建**：现代多模态视频模型具备强大的场景与构图生成能力，通用资产已能提供充分的特征支撑；
  - 除非起始帧（或某一特定帧）真正构成不可或缺的视觉/空间锚点（如第一幕第一人称母爱入画双手与贴近对视），否则可以根据需要选用任何关键帧（中间帧、尾帧），也可以**完全不用任何关键帧（零关键帧纯通用资产直出）**。
- **去编号化纯自然语义命名原则（严禁机械数字编号）**：
  - 视频节点（`%xxx`）与关键帧节点（`@xxx`）**直接使用具备自足视听意图的纯自然语义名称**（如 `%晨光行前准备与元气出发`、`@第一人称揉腮对视`、`%天台特调与三猫开喝`、`@朵朵侧平机位名媛特写`）；
  - **严禁在节点标题中使用“镜头1”、“镜头2”、“起幅帧1”等机械序列编号前缀**。
- **严格剥离硬编码秒数限制**：分镜文本与工程规划描述中不硬编码具体秒数限制。
