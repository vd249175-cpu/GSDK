# 特殊项目判别

为了避免各类垂直题材或特定项目的专属偏好直接平铺堆叠在顶层导航中，GraphVideo 采用**二级项目判别与分发机制**。

当 Agent 开始处理一个项目时，首先应在此文档中**判别当前项目是否命中已沉淀的特定项目规范**。命中时再跳转读取该项目的核心思路与本角色专属技术细节；未命中时则严格遵循通用规范，绝不生搬硬套特定项目的偏好。

---

## 1. 项目判别与流转规则

1. **特征核对**：根据用户指令、剧本大纲、角色设定或现有节点信息，核对是否符合下方任一特定项目的判别特征。
2. **命中特定项目**：
   - 先读取该项目的 `项目核心思路.md`（掌握全局顶层设计与生物/美学硬约束）；
   - 再读取当前 Agent 对应的专属技术细节文档（掌握本岗位的执行铁律）。
3. **未命中（通用项目）**：
   - 严格遵循通用工作流（`project_knowledge.md`、`context_loading.md` 及各 Agent 本地 `details/` 通用规范）；
   - 严禁将特定项目的专有设定（如画外母爱、猫咪生理约束、极简声纹句式等）污染到通用项目中。

## 2. 已沉淀的具体项目规范库

### 1. 治愈系萌宠短剧（猫猫短剧）

- **判别特征**：
  - 以猫咪或萌宠为核心主角的微短剧或短视频；
  - 核心受众为都市女性、主打“沉浸式电子抚养”、假期休闲日常、潮流玩乐、画外母爱（Out-of-Frame）；
  - 或用户明确指定为猫猫短剧/治愈系萌宠题材。
- **项目全局核心思路**：
  - [项目核心思路](./治愈系萌宠短剧/项目核心思路.md)（所有角色必读：受众画像、四幕结构、画外母爱、四足解剖生物学硬约束）
- **各角色专属技术细节**：
  - **Director (编剧兼导演)**：[编剧兼导演技术细节](./治愈系萌宠短剧/编剧兼导演技术细节.md)（剧本 Fountain 格式、双模块导演口述、极简短促对白、角色档案纯粹性）
  - **Storyboarder (视听分镜师)**：[视听分镜技术细节](./治愈系萌宠短剧/视听分镜技术细节.md)（机位稳定优先反碎切镜、宠物等高平视 Pet Eye-Level、人类高机位对比、第一人称 30% 黄金构图、片段式记录生活感）
  - **Planner (依赖规划师)**：[依赖规划技术细节](./治愈系萌宠短剧/依赖规划技术细节.md)（同场景单幕合并生成、双层风格解耦、角色出声声纹硬绑定、极简声纹母带设计 $\le 2-3\text{s}$、单乐器纯净配乐、零关键帧直出、去编号化命名）
  - **Image Prompter (图片提示词师)**：[图片提示词技术细节](./治愈系萌宠短剧/图片提示词技术细节.md)（通用资产底图防烘焙与全景深、两段式关键帧构图、声音与风格资产规范）
  - **Video Prompter (视频提示词师)**：[视频提示词技术细节](./治愈系萌宠短剧/视频提示词技术细节.md)（真实物理动力学表现、叙事动机平稳运镜、原生环境声处理）
