# 镜头复杂度与依赖决策

复杂度分级的目的，是为镜头选择刚好足够的控制方式。它不是质量排名，也不要求每个镜头逐级堆叠依赖。

## 先形成合理的镜头簇

不要机械地把一个分镜条目变成一个视频节点。同一场景和同一情绪段落中的连续动作，可以在模型稳定时长内合并，让生成模型维持自然运镜与上下文。

时长同时考虑台词和画面动作。短促语句或局部特写通常需要约一到两秒，完整长句、情绪反应或动作弧往往需要更长。合并后不超过约十五秒的同场景内容可以形成一个视频节点；更长内容按情节转折、动作接点或运镜逻辑拆成若干子段。最终可用时长仍以当前模型契约为准。

只出现一次的场景或道具不建立独立参考资产。普通环境声和即时拟音优先交给支持原生音频的视频模型，只有跨镜头配乐、贯穿性声音或用户明确要求的对白精播才规划独立音频节点。

## 五种控制程度

### 纯文字直出

没有特定主体锁定，主要是天气、光影、氛围或泛化空镜时，视频节点可以只依赖文字描述。没有真实需要就不挂关键帧或视觉资产。

### 通用参考直出

主体与环境需要保持一致，但起止构图和动作轨迹不需要精确锁定时，视频节点直接引用已有角色、场景、风格或声音资产，不创建专属关键帧。

### 有限关键帧控制

镜头需要明确起幅、特写姿态、某个中间状态或主体构图时，创建少量关键帧。关键帧继续引用其中真正出现的角色、场景、道具与风格。

### 多关键帧或连续镜头控制

复杂运动、多阶段状态变化、首尾过渡或跨镜头接续需要更强约束时，可以使用多个关键帧，或把前序视频作为连续输入。引用数量和输入顺序必须符合当前模型契约。

### 外部空间参考

极端透视、复杂空间穿梭或多主体精确遮挡难以仅靠普通关键帧稳定表达时，可以在关键帧下加入 3D 白模、深度或姿态参考。只有空间关系确实需要时才增加这层成本。

## 模型与声音的选择

选择图片、视频或音频模型前，调用 `list_generation_models`（必要时传入 `mediaType` 或 `modelId`）核验当前可用性、媒体类型、输入模式、引用上限和参数。模型名称与能力可能变化，任何静态推荐都只是候选线索。

音频依赖通常保持浅层：音效或配乐多为零引用直出，角色音色可以由文字设计或单个真实录音克隆，对白演播至多绑定所需角色音色。具体限制仍以模型契约为准。
