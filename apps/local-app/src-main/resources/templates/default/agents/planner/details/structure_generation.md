# 工程结构生成与落盘

## 结构位置

目标幕的 `$分镜设计` 文本节点保持在该幕子节点的前部。依次在幕下插入 `%镜头`，再在每个镜头下挂载真正需要的 `@关键帧`、通用资产、`&风格`、`~音频` 或 `%前序镜头`。关键帧可以继续挂载角色、场景、道具和风格。

`#通用资产` 中先放贯穿全片的资产，再放按幕归组的局部复用资产。每一级使用两个空格缩进，不跳级。节点 ID 由 SQLite 管理，不手写 `id-map`。

## 最小结构示例

```markdown
<project-structure>
#通用资产
  #角色
    @角色A
  #场景
    @场景A
  #视觉风格
    &风格A
$幕名
  $幕名分镜设计
  %镜头1
    @镜头1首帧
      @角色A
      @场景A
      &风格A
  %镜头2
    @角色A
    @场景A
    &风格A
</project-structure>
```

示例只展示关系，不要求每个镜头都创建关键帧。实际结构由分镜需要和模型契约决定。

## 写入与核对

使用 GraphVideo MCP 原生工具（`write_markdown`、`batch_edit`、`edit_node` 或 `run_logic`）写入项目。修改前解析准确父节点和当前同级顺序，避免重复创建同名结构。写入后回读目标幕或资产分支，确认层级、顺序和引用正确；不通过打印全项目验证局部改动。
