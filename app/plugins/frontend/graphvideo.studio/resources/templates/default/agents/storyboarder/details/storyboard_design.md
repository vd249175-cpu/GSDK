# 视听分镜设计

分镜文档是从剧本走向生成工程的视听说明。它应让读者看懂镜头为何存在、画面如何变化、声音在何处发生，也应给 Planner 留下判断生成依赖的空间。

## 开始设计

先从剧本和导演口述提炼本幕的叙事任务、人物状态、空间关系、视听基调和节奏曲线。再把内容划分为若干具有清楚戏剧目的的镜头组。组的边界通常来自场景变化、行动阶段、情绪转折或节奏变化，而不是固定镜头数量。

## 文档结构

正文先写“分镜设计总述”，标明对应幕名，并用简短段落说明核心视听意图和节奏。随后按叙事阶段建立镜头组，每组先概括空间调度、人物状态和声音走向，再逐镜头写具体设计。

每个镜头至少说明：

- 它在叙事中的目的，以及与前后镜头的接点。
- 景别、机位、视角、构图与焦点（第一人称近景主体保持约 30% 黄金自然比例）。
- **单机位可见性**：以摄影机当前位置为准，只描述真正看得到的主体、动作和遮挡关系；镜头外不可见的事实通过后续镜头、运镜或声音对位建立，不把它伪装成当前画面。
- **摄像机运动与连贯性**：优先维持机位稳定，动作变化不大时不切镜；需要转换空间或跟随视线时优先在镜头内使用平滑运镜（推拉摇移跟）而非直接切断。
- 摄像机怎样移动，主体怎样行动，动作从何状态变化到何状态。
- 光线、材质、环境和必要的声音细节。
- 该镜头承载的角色台词，或旁白从哪一句、哪个字句读到哪里。
- **不设定镜头秒数**：分镜关注动作完整弧度与声画对位，不自行给镜头标注具体秒数（秒数与工程时长管理由下游 Planner 负责）。

台词与旁白必须和可见动作的情感节奏相称。连续镜头还要检查人物朝向、视线、动作方向、空间轴线、道具状态、光线和环境声是否自然承接。

## 文本范例

```markdown
# 分镜设计总述

- **剧本幕名**：幕名
- **视听基调**：说明本幕的核心视听意图与节奏变化。

## 第一组：组主题名

> **组视听描述**：概括本组的空间、人物状态、动作演进和声音走向。

### 1. 镜头名称

说明景别、视角与构图。写清摄像机运动、主体动作、焦点和光影变化，并标出该镜头中的人物台词，或旁白从“……”读至“……”。最后说明与下一个镜头衔接的动作或声音。

### 2. 镜头名称

承接上一镜头的方向与人物状态，说明新的机位、动作变化、环境反馈和声画对位。
```

范例提供信息层次，不要求所有镜头使用相同句式。不要在分镜正文中嵌入模型参数、节点 ID 或技术 Prompt。

## 完成核对

写入项目后回读目标分镜节点。检查每个镜头是否有清楚叙事作用，声画对位是否具体，前后连续性是否成立，并确认正文没有越过职责边界进入依赖规划或技术提示词。
