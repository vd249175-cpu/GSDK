# 工作导航

这份导航将通用创作方法、垂直项目偏好与资产层提示词分开。先确定项目语境和目标节点，再只加载图像、风格或音频中的专属写法。

## 先辨认眼前的任务

- 项目是否已明确属于特定题材（如治愈系萌宠短剧等）；没有明确事实时不套用特定题材偏好。
- 目标是可复用角色/场景/道具资产，单一分镜关键帧，独立音频，还是可复用视觉风格。
- 节点的直接依赖、所属幕和分镜是否足以确定本次生成事实。
- 当前 Prompt 的问题来自上游事实缺失、模型契约不匹配，还是资产/关键帧/音频表达本身不够准确。
- 工作只涉及一个节点，还是一组共享上下文的节点；批量任务能否按幕或媒体类型分批处理。
- 请求是否包含视频 `%` Prompt、时长、运镜或硬切；这部分交给 `video-prompter`。

先用局部结构定位目标节点，再读取必要的剧本、分镜与依赖字段。需要浏览本 Agent 的辅助文档时，调用 `list_agent_documents`。

## 导航目录

### [项目知识与结构规范](../project_knowledge.md)

解释基础视频项目目录体系、节点符号语义、本 Agent 可写字段与纯 Prompt 存储约定。每次读写都需要它。

### [上下文感知与分层载入规范](../context_loading.md)

说明前沿聚焦与按需回溯、粗读/略读/精读自适应动态跳转，以及维护 `@图片`、`~音频` 与 `&风格` 描述防止事实漂移的义务。

### [特殊项目判别](../特殊项目判别.md)

汇总当前已沉淀的具体项目规范库（如治愈系萌宠短剧等）。任务开始时先由此判断当前项目是否属于特定题材，并在命中时跳转加载对应的项目核心思路与本角色技术细节；非特定项目则遵循通用规范。

### [职责边界与读写范围](./details/scope_constraint.md)

说明资产层与 `video-prompter`、Planner、分镜师之间的边界。混合请求时先读。

### [图像与关键帧提示词](./details/image_prompt_engineering.md)

覆盖可复用角色、场景、道具资产的全景深中性防烘焙写法，以及视频时间轴关键帧的两段式空间构图写法。

### [视觉风格定义与推演测试](./details/visual_style_engineering.md)

覆盖视觉风格节点的三层正交结构定义（光学/光影/微观材质），以及 1–4 路受控测试变体推演与收敛专属工作流。

### [音频提示词](./details/audio_prompt_engineering.md)

覆盖角色音色与声纹试听、对白演播、拟音和配乐等独立音频资产。

### [提示词维护与自进化守则](../self_evolution.md)

说明如何维护本 Agent 的核心人格、导航和辅助文档，以及严格审批自进化修改流程。普通提示词工作不需要读取。

## 常见的阅读路径

- 所有工作先读 `项目知识与结构规范` → `职责边界与读写范围` → `上下文感知与分层载入规范`。
- 特定题材项目先通过 `特殊项目判别` 读取项目核心思路与图片提示词专属技术细节。
- 图像资产或关键帧进入 `图像与关键帧提示词`。
- 风格定义或推演测试进入 `视觉风格定义与推演测试`。
- 独立音频资产进入 `音频提示词`。
- 查询模型定义或解析 Prompt 时调用 `list_generation_models` 或 `resolve_generation_prompt`；文档只说明如何消费实时契约，不替代它。

## 无法确定时

不清楚节点是否是资产或关键帧，先读取其描述、父级与下游使用方式。不清楚是否属于特定项目，先读 `特殊项目判别`。不清楚字段能否编辑，先读 `职责边界与读写范围`。不清楚模型支持的参数或引用，先查询当前模型契约。通常按“项目语境 → 目标节点 → 上游事实 → 模型契约 → 专属写法”组织工作。
