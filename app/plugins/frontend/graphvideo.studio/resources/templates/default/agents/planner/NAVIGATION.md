# 工作导航

这份导航帮助依赖规划 Agent 从项目阶段、目标幕和预期产物中选择必要知识。它不是条件表；同一个任务可能同时需要理解上下文、判断复杂度、核验模型并落盘结构。

## 先辨认眼前的任务

先看用户希望得到的是整体依赖方案、某一幕的镜头工程树、少量节点修订，还是对 Agent 自身提示词的维护。判断时可以关注：

- 项目处于通用资产沉淀阶段，还是已经有分镜并准备建立生成依赖。
- 当前项目是否属于特定题材（如治愈系萌宠短剧等），需要先通过判别文档进行识别。
- 当前目标覆盖一个节点、一幕、多个幕，还是需要全片统筹。
- 现有结构是否足以判断，是否还需要读取剧本、分镜、邻近幕或关联资产。
- 镜头是否需要聚合、关键帧控制、前序镜头连续输入或外部空间参考。
- 任务是否涉及当前环境里的模型能力、参数范围和引用上限。
- 请求是否越过依赖规划，进入剧本、分镜正文、技术提示词或实际媒体生成。

这些问题不要求一次得出全部答案。先读取最能缩小不确定性的文档，再随任务展开补读。需要查看辅助文档全貌时，调用 `list_agent_documents` 获取标题和简略描述。

## 导航目录

### [项目知识与结构规范](../project_knowledge.md)

解释基础视频项目目录体系、节点符号语义、内容层级与生成依赖的规范。任何结构查询、依赖判断或项目写入都以它为基础；纯粹讨论抽象方法时可以暂缓。

### [上下文感知与分层载入规范](../context_loading.md)

说明如何按多种读取形式（粗读拓扑、略读注解、精读细节与动态跳转）装载上下文，并履行维护 `%镜头` 与 `@关键帧` 描述的义务。

### [特殊项目判别](../特殊项目判别.md)

汇总当前已沉淀的具体项目规范库（如治愈系萌宠短剧等）。任务开始时先由此判断当前项目是否属于特定题材，并在命中时跳转加载对应的项目核心思路与本角色技术细节；非特定项目则遵循通用规范。

### [职责边界与读写范围](./details/scope_constraint.md)

划分 Planner 可以读取和编辑的内容。请求混合了结构规划、技术提示词、剧本修改或媒体生成时，应尽早阅读。

### [前置事实与模型研判](./details/pre_inspection.md)

说明如何在决策前确认项目事实、读取相关规约并核验模型契约。需要推荐模型、决定引用数量或设置生成参数时必须使用。

### [镜头复杂度与依赖决策](./details/dependency_classification.md)

说明镜头聚合、资产复用、音频精简和五级复杂度的判断。把分镜转成关键帧与依赖拓扑时，这是主要工作文档。

### [工程结构生成与落盘](./details/structure_generation.md)

规定镜头、关键帧、资产和风格在项目结构中的位置，并给出最小范例。准备创建或调整节点层级时阅读。

### [提示词维护与自进化守则](../self_evolution.md)

说明如何维护本 Agent 的核心人格、导航和辅助文档，以及严格审批自进化修改流程。普通规划任务不需要读取。

## 常见的阅读路径

- 了解现有依赖结构：`项目知识与结构规范` → `上下文感知与分层载入规范`。
- 特定题材项目规划：`特殊项目判别`（命中后跳转加载项目核心思路与规划专属技术细节）→ `项目知识与结构规范` → `前置事实与模型研判` → `镜头复杂度与依赖决策` → `工程结构生成与落盘`。
- 为已有分镜规划某一幕：`项目知识与结构规范` → `职责边界与读写范围` → `上下文感知与分层载入规范` → `前置事实与模型研判` → `镜头复杂度与依赖决策` → `工程结构生成与落盘`。
- 只修正少量关键帧或依赖：先读 `项目知识与结构规范` 和 `工程结构生成与落盘`；模型契约或复杂度不清楚时再补读对应文档。
- 统筹全片通用资产：`上下文感知与分层载入规范` → `镜头复杂度与依赖决策`，按幕分批形成资产结论，不一次读取全部正文。
- 修改这套提示词：`提示词维护与自进化守则`，再补读受影响主题的细节文档。

## 无法确定时

不清楚项目阶段，先读 `上下文感知与分层载入规范` 并查看顶层结构。不清楚是否属于特定项目，先读 `特殊项目判别`。不清楚镜头需要多少控制，先读 `镜头复杂度与依赖决策` 并核验模型契约。不清楚请求是否属于 Planner，先读 `职责边界与读写范围`。多份文档组合时，通常按照“项目事实 → 上下文范围 → 模型契约 → 依赖判断 → 结构落盘”理解。
