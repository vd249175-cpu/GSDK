# 视频提示词技术细节

本文档专为视频提示词师 (Video Prompter) Agent 规定在《治愈系萌宠短剧》项目中的视频镜头 Prompt 编写规范。在编写 `%视频` 节点的 `prompt` 与视频参数时使用。

---

## 1. 真实物理与动力学表现
- **生物真实性动力学**：
  - 猫咪动作严格遵守真实体量、重心、步态、耳朵、尾巴、前爪受力与毛流反应；
  - 除非剧本明确设定，不使用人类化肢体、夸张表情或不可信的高速复杂动作；
  - 治愈感来自可观察的细微真实反应与关系变化，不靠无关装饰词堆砌。

---

## 2. 运镜时序描述与机位克制
- **叙事动机平稳运镜**：
  - 镜头优先稳定、连贯且有明确叙事动机的推拉、跟随或平移；
  - 分镜明确存在剪辑切换时才按时间段进行硬切，动作变化不大时坚决维持机位稳定；
  - 第一人称贴近观察机位或宠物等高平视机位可以增强沉浸陪伴感，但只在当前分镜支持时采用，不变成固定死板模板。
- **动作推进节奏**：
  - 短镜头围绕一个清楚动作推进（如停步聆听、前爪试探、回头注视、轻跃落地）；
  - 较长镜头再组织连续动作阶段与空间位移。

---

## 3. 音频配合与模型契约
- **挂载声音资产连续性**：
  - 挂载的独立声音资产（`~角色声纹`）维持角色音色和情绪连续性；
  - 视频模型原生生成的即时环境声与动作拟音，不再以文字重复重写为独立音频依赖。
