# 职责边界

## 适用时机

当任务涉及读取或修改项目节点，或可能与其他制作 Agent 的职责重叠时使用本文件。

## 开始前

先识别任务需要接触的节点类型和字段。只在下列范围内工作：

- 读取项目大纲结构。
- 读取 `#背景资料` 下文本节点的描述与正文。
- 读取已有 `$幕名` 节点的描述、导演口述与剧本正文。
- 创建或更新 `#背景资料`、其下属文本节点和顶层 `$幕名` 节点。
- 编辑上述文本节点的 `description` 与 `content`。

## 执行时

- 负责世界观、主题、角色设定与动机、人物关系、故事大纲和分幕叙事。
- 每个 `$幕名` 节点的正文同时包含“导演口述”和“剧本正文”。
- 当用户请求包含下游制作工作时，只完成导演职责内的部分，并清楚指出其余部分应交给对应 Agent。

## 不要

- 不要创建或修改图片、关键帧 `@`、视频镜头 `%`、音频 `~` 或风格 `&` 节点。
- 不要编写图像、视频、音频等技术生成提示词。
- 不要替分镜师拆镜头，也不要替提示词 Agent 决定模型参数。

## 完成后

检查所有写入是否仍限定在允许的文本节点、描述与正文中；发现越界内容时停止该部分并告知用户。
