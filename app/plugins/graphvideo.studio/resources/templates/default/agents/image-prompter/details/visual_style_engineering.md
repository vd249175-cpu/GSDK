# 视觉风格定义与推演测试

视觉风格节点（`&风格`）通过 `content` 字段定义全剧或特定幕次可复用的摄影、光影、色彩与渲染质感。本 Agent 负责正式风格节点的编写，并在用户需要时独立执行受控的风格推演与稳定性测试。

---

## 1. 视觉风格的三层正交结构

风格 `content` 必须严格按照以下三层正交维度编写，文字形成协调统一的视觉取向，**严禁无差别堆叠风格名词，严禁混入具体角色、场景、道具、景别、机位、运镜或剧情动作**：

1. **摄像机与光学**：描述画幅比例、镜头焦段、透视畸变、光圈大小、景深、散景（Bokeh）与光学特性。
2. **光线、色彩与影调**：描述光线性质与方向、色调倾向、明暗光比、影调曲线、Halation（光晕）与胶片颗粒感。
3. **微观材质与渲染**：描述表皮微观纹理、纤维微光、次表面散射（SSS）与物理材质反射。

### 分层解耦与防烘焙
- **全局资产风格**：保持中性平光和全景深（Pan-focus），严禁加入浅景深虚化或特定时间漫反射，避免将光影或背景“烘焙死”在可复用资产中。
- **全片/分幕镜头风格**：负责全片或特定幕次的情绪与光影渲染，可引入电影级光影、微距景深与特定色温。

---

## 2. 风格推演与稳定性测试（专属工作模式）

当用户明确要求探索新风格、比较不同画面基调或校准现有风格时，`image-prompter` 启动专属的受控实验模式。Planner 与 `video-prompter` 不参与该模式。

### 受控实验三原则
1. **统一测试基底**：四张测试图的正文完全一致，使用一个包含具象主体和典型空间的测试场景（不挂载角色、场景或道具图片资产引用，排除上游资产影响），模型、参数、画幅与其他生成条件保持 100% 一致，**风格变体是唯一的实验变量**。
2. **四路风格变体**：建立 `&测试风格_1` 至 `&测试风格_4`，分别表达四种可比较的视觉倾向（如中性写实、暖调胶片、高反差电影感、清冷自然光等），每个 `@风格测试_<n>` 仅引用对应编号风格。
3. **用户偏好驱动迭代**：用户在 Studio 中手动生成测试图并选择偏好编号；`image-prompter` 提炼胜出特征，保留核心结构，在单一可解释维度（如光比、饱和度、颗粒等）进行微调迭代。

### 测试目录结构
```text
#通用资产
  #风格推演测试
    #测试_<待测风格名>
      @风格测试_1
        &测试风格_1
      @风格测试_2
        &测试风格_2
      @风格测试_3
        &测试风格_3
      @风格测试_4
        &测试风格_4
```

### 三阶段流程
1. **初始化**：明确正式风格的复用范围，编写统一测试正文，在 `#通用资产` 下创建测试目录树与四路风格变体。
2. **对比与变异**：用户生成并反馈偏好；保留胜出词汇，仅改变明确的风格维度，更新下一轮候选。
3. **收敛与归档**：用户确认后，提炼最终胜出内容为去实体、去测试场景的纯风格定义，写入正式 `&风格` 节点的 `content`；测试目录按用户意愿保留、归档或清理。
