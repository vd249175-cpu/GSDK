# 工作导航

这份导航只服务视频 `%` Prompt。它将项目语境、上游视觉/音频输入和视频时序写法分开，避免把资产定义或音频正文混进镜头动态。

## 先辨认眼前的任务

- 项目是否已明确属于特定题材（如治愈系萌宠短剧等）；没有明确事实时不套用特定题材偏好。
- 视频是纯文字、图生视频、多关键帧、参考视频接续，还是含有音频参考。
- 分镜是否明确连续运镜还是硬切组合；动作量和镜头位移能否在所选时长完成。
- 依赖是否真实存在、已就绪且符合当前模型的数量与输入顺序。
- 当前问题来自上游事实缺失、关键帧/参考输入不匹配、模型契约不匹配，还是镜头动态表达不够具体。
- 工作是否是一组需要继承朝向、视线、动作接点、空间轴线或声画对位的相邻镜头。
- 请求是否是在写图片、关键帧、音频或风格正文；这些字段交给 `image-prompter`。

先从目标镜头和局部结构读取必要事实，再查询当前视频模型契约。需要浏览辅助文档时，调用 `list_agent_documents`。

## 导航目录

### [项目知识与结构规范](../project_knowledge.md)

说明基础视频项目目录体系、节点符号语义、视频 Prompt 的存储字段、引用和参数边界。

### [上下文感知与分层载入规范](../context_loading.md)

### [特殊项目判别](../特殊项目判别.md)

### [职责边界与读写范围](./details/scope_constraint.md)

说明视频 Agent 与图像/资产 Agent、Planner、分镜师之间的职责分界。

覆盖连续运镜、硬切时间码、不同输入模式和落幅写法。

说明如何维护本 Agent 的核心人格、导航和辅助文档，以及严格审批自进化修改流程。普通视频提示词工作不需要读取。

## 常见的阅读路径

- 每个视频任务先读 `项目知识与结构规范` → `职责边界与读写范围` → `上下文感知与分层载入规范` → `视频镜头提示词`。
- 特定题材项目先通过 `特殊项目判别` 读取项目核心思路与视频提示词专属技术细节。
- 不清楚模型输入方式、时长、引用数量或参数时，先查询当前模型契约再写入。
- 需要处理一组连续镜头时，先以目标幕为边界读取共享剧本和分镜，再逐个视频节点读取直接依赖与必要前序镜头，避免为每个节点重载整幕。

## 无法确定时

不清楚镜头是否连续或存在硬切，先读取对应分镜与邻近镜头。不清楚是否属于特定项目，先读 `特殊项目判别`。不清楚依赖是否有效，查询目标节点和真实直接依赖。不清楚字段职责，停止在视频 `%` Prompt 边界内，不改写资产或音频正文。通常按“项目语境 → 目标镜头 → 上游事实 → 模型契约 → 输入方式 → 动态写法”组织工作。
