# 图片提示词技术细节

本文档专为图片与资产提示词师 (Image Prompter) Agent 规定在《治愈系萌宠短剧》项目中的提示词编写规范。在编写 `@图片`（角色、场景、道具、关键帧）、`~声音` 与 `&风格` 节点的 `prompt` / `content` 时使用。

---

## 1. 资产提示词规范（底图防烘焙与全景深）
- **通用资产中性与防烘焙铁律**：
  - 猫咪角色（`@角色`）、场景（`@场景`）和核心道具（`@道具`）的底图必须保持**清晰、中性、全景深通透自然光**；
  - **绝对严禁将单幕情绪、临时动作姿态、特定镜头光影或浅景深虚化烘焙进通用资产**，确保资产在跨幕跨镜头引用时的纯净度与可复用性。
- **可信尺度与生物表现**：
  - 猫咪的体量、重心、步态、耳朵转动、尾巴平衡、前爪受力、毛发反应和与人/道具的尺度关系保持真实可信；
  - 除非剧本明确设定，不写人类化肢体、夸张表情或不可信的高速复杂动作；
  - 治愈感来自可观察的细微反应与关系变化，不靠无关装饰词堆砌。

---

## 2. 关键帧提示词规范（两段式构图）
- **两段式空间锚定**：
  - 关键帧先建立猫咪、人物、道具和承载表面的空间位置与透视关系；
  - 再锁定一个具有明确叙事动机的可见瞬间（如第一人称温柔抚摸对视）。

---

## 3. 声音与风格资产提示词规范
- **角色音色与情绪连贯**：
  - 角色音色（`~角色声纹`）、跨镜头配乐（`~全片BGM`）或独立拟音保持可辨识与情绪连贯；
  - 视频生成模型能够原生承担的即时动作拟音与环境声，不再额外拆解为独立声音节点。
- **视觉风格一致性**：
  - 严格根据双层风格规范装配底层资产风格（`&真实影视照片风格`）与上层镜头风格（`&治愈系写实电影光影`）。
