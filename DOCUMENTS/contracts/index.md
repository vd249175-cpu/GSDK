# 协作、分发与演进契约 (Contracts & Plans)

本目录记录多插件协作契约、跨 Agent 开发隔离准则、独立分发验收规范以及统一运行实施计划。

## 概念清单

* [插件全景与契约索引 (Plugin Reference)](plugins-reference.md) - GSDK 业务插件规范、当前插件拓扑全景清单（包含 Node、Info、State、Elements）以及内核与 SDK 边界说明。
* [插件发布与协作契约](plugin-collaboration-contract.md) - 统一插件交付、所有权、跨插件协作、折叠建议和可选前端的发布规则。
* [SDK、插件与飞书协作分发契约](distribution-contract.md) - 飞书知识库与群聊双通道分享、镜像 SDK、独立制品、版本兼容及验收要求。
* [多 Agent 独立开发与运行协作指南](multi-agent-run-guide.md) - 命名 run 隔离、目录所有权、Bash 启停生命周期和多 Agent 并行开发规范。
* [统一 run 实施计划](unified-run-plan.md) - 将默认应用、图片段和场景测试迁入同一配置驱动运行机制的阶段与验收计划。
